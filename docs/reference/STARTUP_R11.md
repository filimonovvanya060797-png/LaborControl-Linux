# Запуск R11

R11 сохраняет исправленный механизм запуска R9 и дополнительно конфликт со старым `LaborControl_Core.exe` двумя способами:

1. Внутренний сервер называется `LaborControl_Core_R11.exe`, поэтому распаковка рядом со старой версией не может незаметно оставить старый Core под тем же именем.
2. Core исторически вызывает `rundll32 url.dll,FileProtocolHandler ...` и открывает собственный браузер. R11 запускает Core с `shim` первым в PATH; `shim/rundll32.exe` — пустой локальный процесс, поэтому этот единственный автозапуск браузера подавляется без урезания системного PATH.
3. После обнаружения порта Core оболочка сама открывает `http://127.0.0.1:8779/?shell=timesheet-r11`.
4. Все `/api/*` старого приложения проксируются в Core; новые `/api/tab2/*` обслуживаются оболочкой.

Это позволяет сохранить старую бизнес-логику и показать новый интерфейс в одном окне.
