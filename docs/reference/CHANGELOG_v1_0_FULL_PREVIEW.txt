LaborControl 1.0 — TIMESHEET PREVIEW R4
=======================================

R4 — ПОЛНАЯ ПЕРЕДЕЛКА БЛОКА «ПРОВЕРКА ТАБЕЛЯ»
----------------------------------------------
- Вкладка переименована в «Проверка табеля».
- Внутри оставлены только 4 текущих подпункта:
  Опер-табель / Факт / Проверка / Сверка РВД.
- Упрощённая сводка проблем больше не заменяет Опер-табель.
- Опер-табель построен как «план_факт»: 5 строк на сотрудника и 31 день по горизонтали.
- План автоматически читается из актуального графика LaborControl.
- Добавлена страница сырых данных «Факт» с колонками исходного Excel и вставкой из буфера.
- Сменность факта рассчитывается по правилу исходного макроса:
  06–09 = день, 18–22 = ночь, остальное не определяется.
- «Проверка» работает за одну выбранную дату по всем сотрудникам Опер-табеля.
- Проверка сменности включена отдельно от проверки часов.
- Добавлен отдельный импорт актуального файла СЗ РВД.
- Сверка РВД перенесена по логике VBA: В/ДП + факт > 0, затем сравнение с периодами СЗ.
- Реализованы статусы: Нет в СЗ, Нет подтверждения, Частично, Вне СЗ, Лишний,
  Расхождение, OK, Отгулы.
- Для РВД-1 проверяется соответствие количества дней РВД и дней отгула.
- Сырой факт и текущая СЗ РВД сохраняются в labor_control_tab2.json.
- Добавлены тесты диапазонов день/ночь, сменности, парсинга СЗ РВД и ключевых статусов РВД.

R11 — смена свод в Опер-табеле
- Обычные положительные часы плана (11, 10, 9 и т.д.) теперь определяются как дневная смена.
- 1/N определяется как дневная смена.
- 2/N определяется как ночная смена.
- В, ДП, ОТ, 0 и пустое значение не получают смену.
- Благодаря этому сравнение «смена свод ↔ смена ИСАТ» работает и для обычных значений часов без префикса 1/.
