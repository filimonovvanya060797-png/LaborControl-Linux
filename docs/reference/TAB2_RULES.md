# Проверка табеля R3 — зафиксированные правила

## Опер-табель

Каждый сотрудник занимает пять строк:

1. `план`
2. `смена свод`
3. `факт`
4. `смена исат`
5. `вывод`

Дни месяца расположены по горизонтали (1–31). План всегда читается из текущего
графика LaborControl и не хранится второй независимой копией.

### Часы плана

- `В`, `ОТ`, `ДП` → ожидается 0 часов;
- `11`, `8` и т.п. → ожидается соответствующее число;
- `1/11`, `2/11` → для сравнения часов берётся число после `/`.

### Смена свод

- `1/N` → день;
- `2/N` → ночь;
- простое число часов само по себе смену не задаёт.

## Факт

Рабочий формат путевых листов:

- Табель;
- ФИО;
- Путевой лист с;
- Путевой лист по;
- Часов отработано.

Служебные поля:

- День — день даты начала;
- Время — время начала.

Смена ИСАТ по исходному VBA:

- 06:00–09:59 → день;
- 18:00–22:59 → ночь;
- прочее время → смена не определена.

## Проверка выбранного дня

Проверяются все сотрудники Опер-табеля:

- рабочий план есть, факта нет/0;
- плановые и фактические часы отличаются;
- обе смены определены, но отличаются;
- факт есть, а `смена свод` отсутствует (кроме В/ОТ/ДП);
- факт есть, а `смена исат` не определилась (кроме В/ОТ/ДП).

## Сверка РВД

Фактический кандидат РВД:

`план = В или ДП` + `факт > 0 часов`.

После этого данные сопоставляются с актуальным файлом СЗ РВД.
Рабочий шаблон СЗ читается с листа `Общий`:

- K — табельный номер;
- L:M — период РВД;
- P — вид привлечения 1/2;
- Q:R — период отгула.

Статусы:

- `Нет в СЗ` — фактический кандидат РВД есть, сотрудника/периода в СЗ нет;
- `Нет подтверждения` — период в СЗ есть, но факта нет;
- `Частично` — подтверждена только часть РВД-2;
- `Вне СЗ` — фактическая работа В/ДП находится вне всех периодов СЗ;
- `Лишний` — сотрудник есть в СЗ, но отсутствует в Опер-табеле;
- `Расхождение` — РВД-1 не совпадает по факту/отгулам;
- `OK` — РВД-2 полностью подтверждён;
- `Отгулы` — РВД-1 полностью подтверждён и число дней отгула совпадает.
