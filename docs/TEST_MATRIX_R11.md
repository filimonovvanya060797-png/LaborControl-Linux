# LaborControl R11 — матрица полного функционального тестирования

**Создано:** 20.11.2026  
**Цель:** сначала восстановить функциональность Windows R11 на ALT Workstation K 11.4 (VirtualBox), затем обнаруживать регрессии и исправлять ошибки. Не подменять функциональные тесты простой проверкой компиляции.

## Правила статусов

- **Не реализовано** — функция ещё не восстановлена в Linux-порте.
- **Проверка запланирована** — имеется сценарий, но ещё нет автоматического теста.
- **Автотест готов** — сценарий проверяется автоматически, однако тест ещё не запускался на Альт Linux.
- **Пройдено на Альт Linux** — тест действительно исполнен в ALT Workstation K 11.4.
- **Совпало с эталоном R11** — результат подтверждён сравнением с эталонными данными Windows R11, где они доступны.
- **Ошибка** — выявлено расхождение/сбой, требуется исправление.

Эталон: приоритет имеют зафиксированные правила R11 и результат работы Windows-версии. Правила R3/R9, отличающиеся от R11, фиксировать как исторические, а не автоматически считать верными.

## Ограничения текущей версии

- Проверка в GitHub-hosted Ubuntu успешно проходит для технической Linux-адаптации **контроллера R9**, но **не подтверждает** полноценную LaborControl R11.
- В репозитории отсутствует актуальный исходный код Windows Core v0.9.11/R11. Поэтому бизнес-сценарии пока нельзя объявлять пройденными.
- Разукрашка и отдельная Проверка ДП указаны документацией R11 как отложенные функции, не выдавать их за готовые возможности R11.
- Нельзя использовать реальные персональные данные в GitHub Actions или открывать тестовому агенту папку с рабочими базами.

## Этапы тестирования

1. **Базовая автоматизация:** проверка CI на GitHub и установка self-hosted runner для ALT Workstation K 11.4.
2. **Безопасный smoke-test ALT:** ОС, Go, Git, разрешённые пути и изолированная сборка.
3. **Восстановление Core:** минимальные API-контракты, тестовая база, затем бизнес-логика.
4. **Покрытие всей матрицы:** unit + API + интеграционные + браузерные проверки.
5. **Проверка соответствия R11:** эталонные сценарии Windows на обезличенных данных и ручная приёмка.

**Важно:** если тесты не покрывают функцию, CI не способен подтвердить её правильную работу.
