# LaborControl R11 — план ручных испытаний «АвтоГраф», этап 1: связь с «Сотрудниками»

**Дата составления:** 23.11.2026. **Среда:** экспериментальная ALT Linux R11/GTK на изолированной синтетической базе. **Стадия:** план, тесты ниже не считать завершёнными до доказательства. Достоверные результаты фиксировать как `PASS_ALT_SCREENSHOT`, `PASS_ALT_USER`, `FAIL_ALT`, `BLOCKED`, `NOT_RUN`.

## Основание и уже проверенные факты

- Раздел «Сотрудники» принят пользователем; повторять CRUD и весь цикл массового импорта не требуется. Пройден пакетный XLSX-тест: новый сотрудник №9001 «Тестов Иван Сергеевич», должность «Водитель», без пункта сбора и вида графика; №17 «Проверкин Антон Олегович» получил должность «Водитель-испытатель», сохранил «Колонна 1», пункт «Омск», приём 07.10.2024. Данные подтверждены скриншотами в «Сотрудниках» и «АвтоГрафе».
- На скриншоте пользователя от 23.11.2026 справочник «АвтоГраф → Виды графиков» **пуст**. Не пытаться проверять несовместимость, пока не создан отдельный синтетический вид графика.
- Код `port/controller/r11_original.html`: `employeeLifecycleStatus`, `employeeStatusHtml`, `graphPeriod`, `scheduleTypes` определяют статусы, видимость примечания, контроль дат и фильтрацию видов графиков; карточка использует `ehire`, `efire`, `eprob`, `eprobend`, `emainready`, `enotes`.
- `docs/R11_TEST_PLAN_20261123.md`, `docs/R11_SCREENSHOT_AND_REGRESSION_STANDARD_V7_RU.md`, `docs/R11_EMPLOYEE_CARD_MANUAL_RESULTS_20261122.md`, `docs/TEST_MATRIX_R11.md`, `docs/R11_AUTOGRAPH_2026_XLSB_GRAPH_BEHAVIOR_NOTES.md` — исходные требования.

## Безопасность и порядок

1. Только учебные карточки на изолированном экспериментальном профиле. Реальные Windows R11 / SAP / ИСАТ данные не использовать.
2. Сначала получить контрольную резервную копию экспериментальной базы перед изменением испытательного срока, увольнения, графиков или редакций. Не менять №17 для тестов новых статусов; использовать №9001 при согласии пользователя.
3. Проводить **один короткий шаг за раз** и просить **один нужный скрин**, не переснимать всё ранее проверенное. На скриншоте нужны именно результат и правильный тестовый сотрудник; не раскрывать реальные персональные сведения.
4. Изменение кадровых данных №9001 в АвтоГрафе тестировать только после подтверждения, что программа выделяет дату и статус без удаления уже внесённых дней. Тестирование официальной редакции — отдельный этап и отдельная резервная копия.
5. Не интерпретировать надпись «График без официальной редакции» как неисправность; для сотрудника без заведённого вида графика это ожидаемый исходный статус.

## Этап 2. Функциональность самого «АвтоГрафа» — отдельная очередь

- **AG-GRAPH-01**: виды графиков, парные графики, привязка к пункту сбора и согласованным полётам; никакого автоматического выбора типа по одной дате приёма.
- **AG-GRAPH-02**: Конструктор — работа с фазами A/B, датами рейсов, правильными ДП; проверка по обезличенному эталону Windows R11.
- **AG-GRAPH-03**: месячный и годовой график, допустимые значения часов и кодов дней, сохранение/массовое редактирование/отмена.
- **AG-GRAPH-04**: производственный календарь, отпуск, квартальный/годовой учёт, нормы и баланс; математическая сверка эталона.
- **AG-GRAPH-05**: редакции/версии, создание, история, восстановление, отсутствие потерь уже внесённых дней; после отдельной резервной копии.
- **AG-GRAPH-06**: переключение года, согласованные полёты, сохранение фаз; синтетический тест на границе 31.12/01.01.
- **AG-GRAPH-07**: регрессия производительности на 450 тестовых сотрудников и многолетней истории, отдельно от обычных экранных smoke.

Полное совпадение Windows R11/Excel нельзя утверждать без пары входных наборов и сравнения результатов.

## Согласованная идея: уведомление внутри LaborControl об окончании испытательного срока

**Пожелание пользователя подтверждено 23.11.2026.** Уведомление должно отображаться **только в интерфейсе LaborControl**, без интеграции с системными уведомлениями Альт Linux и без всплывающих сообщений ОС. Когда испытательный срок близок к завершению, программа напоминает технику подготовить постоянный (основной) график.

- Внутри уведомления обязательна кнопка **«Открыть график»**, переходящая в **«АвтоГраф» → «График сотрудника»** с автоматическим выбором правильного сотрудника.
- Синтетический тест: уведомление для **№9001 «Тестов Иван Сергеевич»** должно открывать именно №9001. Этот номер — пример, а не жёстко прописанная привязка.
- Переход ничего не записывает в базу и не изменяет план или редакции.
- Не показывать дубли; после подтверждённого перехода на основной график уведомление снимается. Вопросы порогов времени и повторов уточняются при реализации.
- **GitHub Issue:** https://github.com/filimonovvanya060797-png/LaborControl-Linux/issues/19
- **Статус:** утверждённая концепция будущей функции, **НЕ РЕАЛИЗОВАНО**. Сейчас код не меняем; продолжаем тестирование АвтоГрафа.

## Следующее единственное действие пользователю

**Продолжение AG-EMP-07, граница даты приёма:** на учебной базе после резервной копии открыть «Сотрудники» → №9001 и изменить только дату приёма **01.11.2026 → 05.11.2026**; испытательный срок оставить до 20.11.2026, основной график не подготовлен. Сохранить, открыть «АвтоГраф → График сотрудника» → ноябрь 2026. Ожидаем отображение дат **05–20 ноября**, отсутствие 01–04 ноября. Скриншот календаря. После фиксации теста **восстановить 01.11.2026** отдельным шагом. Дату увольнения и невозможность редактирования за пределами периода проверить отдельно.
