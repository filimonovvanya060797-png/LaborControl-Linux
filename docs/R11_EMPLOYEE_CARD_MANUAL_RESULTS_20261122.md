# LaborControl R11 — ручные проверки карточки сотрудника (ALT Linux)

**Дата:** 2026-11-22. **Среда:** экспериментальная GTK-сборка на ALT Linux, синтетические данные. **Сотрудник:** табельный №22 («Ручнов Сергей Александрович»; в пользовательской записи ФИО, регистр, подразделение и дата отличаются от предложенного ассистентом примера — ориентироваться на реально введённые данные).

## Подтверждено пользователем

| Код | Сценарий | Статус | Свидетельство |
|---|---|---|---|
| EMP-CARD-01 | Создание №22 через карточку с отметкой «Квартальщик» | PASS_ALT_SCREENSHOTS | Новая запись №22 в общем списке, карточка открыта повторно |
| EMP-CARD-02 | Редактирование существующего №22, смена на годовой график | PASS_ALT_USER | Пользователь подтвердил, что изменения сохранились и видны в АвтоГрафе |
| EMP-CARD-03 | Повторное открытие после редактирования | PASS_ALT_USER | Поля снова отображаются корректно |
| EMP-CARD-04 | Попытка создать ещё одного сотрудника с табельным №22 | PASS_ALT_USER | Программа не позволила создать дубликат |
| EMP-CARD-05a | Попытка сохранения без табельного номера | PASS_ALT_USER | Сохранение отклонено |
| EMP-CARD-06 | «Очистить» | NEEDS_CLARIFICATION | Пользователь: «кнопка очистить очищает именно поле а не полностью все». Нужно уточнить, какие именно поля очищаются и не затрагивается ли сохранённая запись. Не трактовать как PASS/FAIL до подтверждения |
| EMP-CARD-07 | Испытательный срок, связь галочки и даты, показ в АвтоГрафе | NOT_RUN | Пользователь попросил объяснить тест |
| EMP-CARD-08 | Примечание сохраняется и отображается после возвращения в карточку | PASS_ALT_USER | Пока **не** показывается в графике АвтоГрафа; требование #14 |
| EMP-CARD-09 | Сохранение без ФИО | NOT_RUN | Нельзя приписывать к проверке отсутствующего табельного номера |
| EMP-CARD-10 | Перезапуск программы и проверка сохранности карточки №22 | NOT_RUN | Пока не подтверждено |

## Важные наблюдения

- В UI карточки ранее видно состояние: «Квартальщик» включён, «Испытательный срок» выключен, но дата конца испытания заполнена (14.04.2027). Нужна проверка влияния неконсистентной записи на отображение статуса и расчёт.
- В коде `employeeLifecycleStatus(e)` уже предусмотрено уведомление об окончании испытания (за 14 дней), а `employeeStatusHtml(e,'graph')` участвует в построении страницы АвтоГраф. Тест на ALT остаётся обязательным. В задаче #14 добавлено требование показывать карточное примечание непосредственно на странице сотрудника АвтоГрафа.
- При тесте использовать только сотрудника №22, не менять рабочую Windows-базу.
- Скриншоты из текущей сессии: библиотека `/LaborControl R11/Инструкция/Сотрудники/EMP-CARD-01/`.

**Ограничение:** PASS_ALT_USER — сообщение пользователя о проверке, не независимый автоматический тест, не совпадение с Excel/Windows R11.
