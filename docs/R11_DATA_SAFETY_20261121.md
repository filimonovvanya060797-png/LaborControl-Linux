# Защита данных экспериментального Linux R11 — 21.11.2026

Ветка: `feature/r11-data-safety-20261121` (ответвлена от `feature/r11-linux-core-restore-20261120`, без слияния).

## Изменения
- CSV-импорт факта отклоняет некорректные и нечисловые значения часов с номером строки; ранее ошибка `ParseFloat` игнорировалась и ошибочное значение могло записаться как 0. Импорт с такой ошибкой полностью отменяется до записи JSON.
- Восстановление технической версии графика проверяет наличие массива дней, принадлежность одному сотруднику и году, корректность дат, уникальность дат/ID и отсутствие конфликта ID с остающимися днями. Некорректный снимок отклоняется без записи базы.
- Регрессионные тесты используют только синтетические записи и временные каталоги.

## Границы
Изменения не подтверждают эквивалентность с Windows Core R11, АвтоГрафа, норм часов или сверки ИСАТ/SAP. База пользователя не используется. Существующая экспериментальная сборка остаётся без изменений до отдельного тестирования.
