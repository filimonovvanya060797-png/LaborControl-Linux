# Инструкция LaborControl R11 — сотрудники

**Разделы:** массовый импорт сотрудников; шаблон пунктов сбора/вылета; создание и редактирование карточки.

**Версия инструкции:** 22.11.2026, редакция для согласования. Текст адресован технику, который впервые открывает программу. Все сведения в примерах — учебные. Примечания о тестировании и внутренние GitHub-задачи вынесены в отдельный журнал.

## 1. Массовое добавление сотрудников из Excel

### Для чего
Если нужно завести сразу много сотрудников, удобнее загрузить их из одного файла Excel, чем заполнять карточки по одной.

### Шаг 1. Откройте раздел «Сотрудники»
В левой части LaborControl нажмите **«Сотрудники»**. Найдите блок **«Импорт сотрудников из файла»**.

### Шаг 2. Выберите Excel-файл
1. Нажмите **«Выбрать файл»**.
2. Найдите на компьютере таблицу `.xlsx` с сотрудниками.
3. Выделите файл и нажмите **«Открыть»**.
4. Убедитесь, что название появилось возле кнопки.

В таблице должны быть **табельный номер** и **ФИО**. Дополнительные столбцы могут присутствовать: программа покажет, сколько из них использует.

### Шаг 3. Прочитайте файл
Нажмите **«Прочитать файл»**. Программа покажет проверку перед записью. Сопоставьте названия столбцов и убедитесь, что она правильно определила табельный номер, ФИО, должность, подразделение и даты.

### Шаг 4. Проверьте предварительный просмотр
Верхние показатели означают:

- **Новых** — сотрудники, которых пока нет в базе.
- **Изменятся** — существующие сотрудники, у которых в Excel изменились данные.
- **Уже есть** — сотрудники, данные которых совпадают.
- **Ошибок** — строки, которые нужно исправить.

Посмотрите таблицу ниже показателей. Особенно важно правильно сопоставить **табельные номера и ФИО**.

**Если ошибки есть:** нажмите **«Отмена»**, исправьте файл Excel и прочитайте его снова. Нельзя загружать ошибочные строки.

### Шаг 5. Подтвердите импорт
Если показатели верные и ошибок нет, нажмите **«Импортировать новые и изменения»**. Ознакомьтесь с сообщением: сколько сотрудников будет создано и сколько обновлено. Подтвердите действие.

### Шаг 6. Проверьте результат
Прокрутите страницу до блока **«Список»**. Найдите нескольких сотрудников из файла и сравните табельные номера, ФИО, подразделения и даты.

**Важно:** повторная загрузка того же файла не должна создавать дубли сотрудников. Если данные не изменились, программа сообщит, что новых или изменившихся сотрудников нет.

## 2. Назначение пунктов сбора и вылета через шаблон

### Для чего
Сразу назначить город вылета нескольким сотрудникам. Программа сопоставляет строки по **табельному номеру** и меняет **только пункт сбора/вылета**.

### Шаг 1. Найдите нужный блок
Откройте **«Сотрудники» → «Шаблон пунктов сбора / вылета»**. Показатель **«Без пункта сбора»** сообщает, скольким сотрудникам нужно назначить город.

### Шаг 2. Скачайте шаблон
Нажмите **«Скачать шаблон для Excel»**.

- В установке, которая проходила первоначальную проверку, файл выгружался как CSV. Во встроенном окне GTK его скачивание не срабатывало; временно можно открыть LaborControl в Chromium GOST по `http://127.0.0.1:8779/r11`, пока открыто приложение, и скачать оттуда.
- В новой исправляемой версии кнопка будет отдавать настоящий **Excel XLSX**. Применение исправления в ALT Linux ещё требует подтверждения.

### Шаг 3. Заполните города
Откройте шаблон. В строках с сотрудниками заполните только столбец **«Пункт сбора / вылета»**. Не меняйте табельные номера, ФИО и названия столбцов.

Примеры городов, доступных в текущем справочнике: **Сургут, Уфа, Саратов, Ленск, Иркутск, Тюмень, Новосибирск, Омск**. Используйте только реальные пункты из вашего справочника, а не произвольные названия. Сохраните Excel-файл.

### Шаг 4. Проверьте заполненный шаблон
1. Нажмите **«Выбрать файл»**.
2. Укажите заполненный `.xlsx`.
3. Нажмите **«Проверить шаблон»**.
4. Посмотрите строки и показатели: **«Обновятся»**, **«Без изменений»**, **«Не заполнено»**, **«Ошибок»**.

**Если ошибка:** исправьте проблемную строку. Программа должна предупреждать о неизвестном городе, повторяющемся табельном номере, неизвестном сотруднике, пустом номере и несовпадении ФИО.

### Шаг 5. Запишите пункты сбора
Если всё верно, нажмите **«Внести пункты сбора»**, затем подтвердите действие.

### Шаг 6. Проверьте результат
Проверьте столбец **«Пункт сбора»** у нескольких сотрудников в общем списке. Показатель **«Без пункта сбора»** должен уменьшиться. Если заполнены все сотрудники — он станет **0**.

Чтобы убедиться, что повторная загрузка ничего не меняет, ещё раз прочитайте тот же файл. Тогда должно быть **«Обновятся: 0»**, а остальные строки — **«Без изменений»**.

## 3. Создание сотрудника вручную

### Для чего
Добавить одного нового сотрудника, не готовя общий Excel-файл.

### Шаг 1. Откройте пустую карточку
Перейдите в **«Сотрудники» → «Карточка сотрудника»**. Если вместо пустой формы отображаются данные другого сотрудника, нажмите **«Очистить»** и убедитесь, что вводите новые данные.

### Шаг 2. Заполните основные данные
Введите **табельный номер**, **ФИО**, **должность**, **подразделение**, **пункт сбора/вылета** и **дату приёма**. Не используйте уже существующий табельный номер. Дата увольнения для действующего сотрудника остаётся пустой.

### Шаг 3. Выберите настройки графика
- **Вид графика** выбирайте из доступных для выбранного пункта сбора. Если тип ещё не заведен, оставьте **«Не назначен»** — позже нужно настроить соответствующий график.
- **Квартальщик** отмечайте только для сотрудника с квартальным учётом.
- **Испытательный срок** отмечайте, если он действительно установлен, и указывайте точную дату окончания.
- **Основной график подготовлен** отмечайте, когда постоянный график реально готов.

### Шаг 4. Заполните примечание (по необходимости)
В поле **«Примечание»** можно написать важную информацию: почему график пока не подготовлен, что нужно уточнить, какие особенности учесть. Поле необязательное.

После обновления LaborControl примечание должно показываться непосредственно на странице сотрудника в **АвтоГрафе**. До установки исправления его можно прочитать в самой карточке.

### Шаг 5. Сохраните сотрудника
Нажмите **«Сохранить»**. Программа должна подтвердить сохранение. Найдите нового сотрудника в блоке **«Список»**.

### Шаг 6. Проверьте и при необходимости исправьте данные
Нажмите напротив сотрудника **«Изменить»**. Его поля откроются в верхней карточке. Внесите изменения и снова нажмите **«Сохранить»**.

Изменённый вид графика должен появиться и в разделе **«АвтоГраф»** у того же сотрудника.

## 4. Испытательный срок в АвтоГрафе

Если у сотрудника включён испытательный срок, на странице его графика должны быть видны **факт испытательного срока и дата его окончания**. За 14 дней до окончания программа должна сообщать о необходимости подготовить постоянный график. После подготовки предупреждение должно смениться подтверждением готовности. Для сотрудника, увольняющегося во время испытания, постоянный график может не требоваться.

**Важно:** в текущей установленной версии ALT Linux пользователь не увидел эту информацию в АвтоГрафе; исправление внесено в ветку разработки, но не проверено на его компьютере. Этот пункт будет оформлен окончательно после обновления и новых скриншотов.

## 5. Если что-то пошло не так

- **Номер занят:** проверьте, не существует ли уже сотрудник с таким табельным номером.
- **Сотрудник не сохранился:** проверьте обязательные поля и даты.
- **Вид графика не выбирается:** сначала проверьте пункт сбора и заведённые виды графиков.
- **В Excel неизвестный пункт:** выберите название из справочника.
- **Сотрудник не появился после импорта:** вернитесь к предпросмотру и найдите ошибочную строку.

**Правило безопасности:** рабочую Windows-базу не использовать для учебных проверок. Изменения массовых данных подтверждать только после проверки предпросмотра.
