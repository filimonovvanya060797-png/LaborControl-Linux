# LaborControl R11 — ручные проверки массового импорта сотрудников (ALT Linux)

**Дата фиксации:** 2026-11-22 (после серии проверок 2026-11-21/22).
**Среда:** установленная пользователем экспериментальная сборка ALT Linux/GTK.
**Данные:** только вымышленные сотрудники; первоначальный №1 в тестовой базе, импорт №2–16 (15 человек), затем №17–21 (5 человек). Не использовать рабочую Windows-базу.

> Статус `PASS_ALT_USER` означает, что пользователь **сообщил** об успешном результате на ALT Linux. Это не автоматическая проверка GitHub, не независимое удалённое чтение его базы и не доказательство соответствия версии Windows R11.

## Вывод

**Основной текущий пользовательский сценарий массового импорта на ALT Linux проверен и может быть закрыт как этап ручного тестирования с зафиксированными замечаниями.** Это не означает полного покрытия всех негативных сценариев и не закрывает проверку Excel/CSV-паритета, атомарности массовых изменений при сбое, реальной производительности на ~450 сотрудниках или совпадения с Windows R11.

Для пользовательского руководства использовать чистовые скриншоты в библиотеке «LaborControl R11 / Инструкция / Сотрудники», без упоминаний тестов. Отдельно проводить сверку текста руководства с пользователем и заменять снимки после русификации диалогов.
