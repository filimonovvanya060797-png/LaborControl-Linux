# LaborControl R11 — план проверок на 23 ноября 2026 года

**Область:** «Сотрудники» (карточка, массовый импорт, шаблон пунктов сбора) и их связь с **«АвтоГраф → График сотрудника»**. СЗ РВД, «разукрашка» и остальные функции пока вне этапа.

**Основание:** ручные тесты пользователя на ALT Linux от 21–22 ноября и замечания GitHub #8, #9, #10, #11, #12, #14. **Это план**, а не утверждение о прохождении завтрашних тестов.

## До начала

1. Убедиться, что новая экспериментальная сборка из ветки `fix/r11-ux-and-employee-20261122` прошла Go API/unit, JavaScript static и GTK smoke CI. Любая ошибка означает **BLOCKED**, до починки не устанавливать.
2. Перед заменой приложения создать свежую резервную копию **тестовых данных** каталога `~/.local/share/LaborControl-R11-Desktop-Experimental/LaborControl`. Сохранить прежнюю сборку для отката. **Не трогать рабочую Windows-базу.**
3. Установить новую сборку отдельно, проверить номер/commit, а не только ярлык интерфейса.
4. Работать только с тестовыми сотрудниками, особенно №22. Инструкция с номерами и стрелками должна соответствовать реальному экрану после обновления.
