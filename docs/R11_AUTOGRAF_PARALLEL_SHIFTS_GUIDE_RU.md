# АвтоГраф — что означает «Первая последовательность: Рабочая / Свободная»

Материал для встроенной инструкции LaborControl R11 и будущей иллюстрированной редакции V8/V9.  
Дата фиксации: **24.11.2026**. Проверено по функциям `flightSeq`, `seqPhase`, `buildByFlights` и фактическому экрану ALT Linux «Виды графиков». Иллюстрация пользователя: `Снимок экрана_20261124_015128.png` — вложение беседы, ещё не добавленное в ресурсы программы.

## Простое объяснение для сотрудника, который впервые открыл программу

**Рабочая вахта** — период в цикле, для которого сотруднику при назначении соответствующего вида графика планируются рабочие дни. **Свободная вахта** — противоположный период цикла, когда работнику не планируют рабочие дни по этому вахтовому графику.

**Первая последовательность** — первая из двух чередующихся последовательностей согласованных рейсов (ДП). Само слово «первая» **не означает первое число месяца, первый рабочий день или первую запись в справочнике**. Первую последовательность задаёт первая опорная ДП в общем цикле; вторую — вторая опорная ДП; затем они чередуются с установленным циклом полётов.

В поле **«Первая последовательность первого графика»** нужно выбрать, какая вахта начинается **с первой последовательности рейса** для сотрудника, которому впоследствии назначат этот вид:

- **Рабочая** — после первой опорной ДП начинается рабочая фаза первого вида. После второй опорной ДП — свободная. У парного вида наоборот.
- **Свободная** — после первой опорной ДП начинается свободная фаза первого вида. После второй — рабочая. У парного вида наоборот.

Один и тот же **общий цикл дат полётов** используется для обоих видов. Создавать отдельные рейсы для каждого из них не нужно. Два вида отличаются не рейсами, а тем, кому в соответствующие периоды планируется рабочая или свободная вахта.

## Пример на вашем цикле Тюмени — 2026 год

Пользователь подтвердил соглашение о названиях: отсутствие/наличие **точки в конце** — значимое различие между двумя парными видами, а не ошибка набора.

| Согласованная ДП | Какая последовательность рейса | **Тюм-Тал-Тюм 9** | **Тюм-Тал-Тюм 9.** |
|---|---|---|---|
| **09.01.2026** | Первая | Рабочая вахта | Свободная вахта |
| **30.01.2026** | Вторая | Свободная вахта | Рабочая вахта |
| **27.02.2026** | Первая | Рабочая вахта | Свободная вахта |
| **27.03.2026** | Вторая | Свободная вахта | Рабочая вахта |

Таблица указывает **фазу периода, открываемого соответствующей ДП**. Сам день полёта учитывается отдельно как **ДП**, а не автоматически как обычный рабочий день по 11 часов. В действующей базовой логике Конструктор применяет 11-часовые дни в рабочей фазе, свободную фазу помечает «В», а ДП — отдельным типом дня. 10-часовые участки редактируются после построения по установленным правилам.

**Пример словами:** для вида **«Тюм-Тал-Тюм 9»** после ДП 09.01.2026 идёт рабочая вахта до следующей ДП 30.01.2026; после 30.01.2026 — свободная до следующего рейса 27.02.2026. Для вида **«Тюм-Тал-Тюм 9.»** всё наоборот. Даты рейсов при этом общие.

## Как создать парные виды в новой версии

1. Откройте **«АвтоГраф → Виды графиков»**.
2. В блоке **«Создать два парных графика»** выберите пункт сбора (например, Тюмень).
3. Введите **одно** название **без точки**: `Тюм-Тал-Тюм 9`.
4. В поле «Первая последовательность первого графика» выберите **«Рабочая»** (если именно этот вид должен начинаться с рабочей вахты).
5. Прочитайте подсказку-предпросмотр: программа сама показывает `Тюм-Тал-Тюм 9` (первая рабочая) и `Тюм-Тал-Тюм 9.` (первая свободная).
6. Нажмите **«Создать оба графика»**. В таблице должны появиться две связанные строки с отметками **«Пара готова»**.

Если один вид уже создан старым способом, **не нужно заново заполнять форму**. В его строке нажмите **«Создать парный»** — программа сама добавит недостающий вид с точкой и противоположной фазой. При конфликте с уже существующим названием программа откажется от изменения без молчаливой перезаписи.

## Что важно не путать

- «Рабочая» / «Свободная» **не выбирает 10 или 11 часов** и не означает «работа/выходной только в день полёта».
- **Создание пары не назначает вид конкретному сотруднику** и не записывает ему график. Назначение вида и построение плана — отдельные действия, выполняемые позже после проверки сотрудника, дат трудоустройства, увольнения и согласованных ДП.
- **Создание пары не изменяет согласованные полёты**: обе строки лишь интерпретируют общий цикл с противоположных сторон.
- «Свободная вахта» в этом контексте не является отпуском, больничным или увольнением. Такие события учитываются отдельно.
- Для **нестандартных** взаимосвязей есть свёрнутый блок «Ручная настройка и нестандартные пары». Большинству пользователей он не требуется.
- В действующем экспериментальном ПО смена даты **опорного полёта** в единичном редакторе имеет известное ограничение согласованности (#28); не использовать редактирование отдельной опорной ДП для сдвига целого цикла без отдельного утверждения.

## Если парные графики имеют разные номера

**Точка в конце — это один из принятых способов назвать пару, но не обязательное правило всех направлений.** На одном пункте сбора могут быть графики с разными номерами. Если по фактическим утверждённым правилам «Сург-Тал-Сург 7» и «Сург-Тал-Сург 16» составляют пару, пользователь должен прямо указать эту связь; программа **не угадывает её по числам и не подменяет автоматически вариантом «7.»**.

### Две новые записи

1. Во вкладке «Виды графиков» выберите пункт сбора, например «Сургут».
2. Введите название первого графика «Сург-Тал-Сург 7» и выберите первую последовательность «Рабочая» либо «Свободная» по действующему графику.
3. В поле **«Как выбрать второй график?»** выберите **«Другое название / существующий график»**.
4. В появившемся поле введите точное имя второго графика «Сург-Тал-Сург 16» или выберите его из предложенных записей того же пункта сбора.
5. Проверьте предварительный текст двух имён и противоположных первых фаз. Нажмите **«Создать оба графика»**. Если второй вид уже существует, программа проверит его фазу и связь, а не создаст дубль. Неподходящую фазу или занятую чужую пару программа должна отклонить, ничего не переписывая.

### Первый вид уже создан

В строке вида без готовой пары выберите **«Выбрать другого»**. Укажите точное название второго вида — нового или уже заведённого — и нажмите **«Создать или связать пару»**. Программа сохранит безопасную взаимную связь, если нет конфликтов; существующую готовую пару она не разорвёт автоматически. Кнопка **«Создать парный»** по-прежнему подходит для ранее указанного имени и не требует повторно заполнять форму.

Не путать «несколько видов графиков» и «несколько независимых циклов согласованных дат»: это **разные сущности**. У текущего Конструктора даты полётов выбираются по пункту сбора. Если у одного пункта действительно есть разные самостоятельные циклы полётов, перед построением рабочих планов требуется подтвердить правило их разграничения — см. GitHub issue #33. Нельзя объединять два цикла только по совпадению пункта сбора без проверки.
