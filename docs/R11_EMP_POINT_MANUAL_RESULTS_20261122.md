# LaborControl R11 — ручная проверка шаблона пунктов сбора / вылета

**Тест:** EMP-POINT-01, ALT Linux, 22 ноября 2026. Источник: пользовательские скриншоты и скачанный CSV/преобразованный XLSX; испытания проводят на тестовых сотрудниках.

## Входные данные

- 20 вымышленных сотрудников, табельные №2–21, без пункта сбора (№1 имел пункт сбора «Тюмень»).
- Кнопка экспорта создаёт CSV с 20 строками, хотя в UI подписана «Скачать шаблон для Excel». В Chromium GOST CSV скачался; в GTK/WebKit выдала только всплывающее уведомление. Открыть CSV привычной программой у пользователя не удалось, поэтому файл конвертирован в XLSX. См. issue #11.
- Для обратного импорта подготовлен XLSX с восемью городами, из разрешённого программой справочника: Сургут, Уфа, Саратов, Ленск, Иркутск, Тюмень, Новосибирск, Омск.

## Скриншоты пользовательского теста

Хранятся в ChatGPT Library: `/LaborControl R11/Инструкция/Сотрудники/EMP-POINT-01/`.

- `03_Начальный_экран_пункты_сбора_20.png` — перед загрузкой 20 сотрудников без пункта.
- `04_Диалог_выбора_Excel.png` — выбор файла в системе.
- `05_Выбранный_файл_Excel.png` — XLSX выбран.
- `06_Предпросмотр_обновятся_20_ошибок_0.png` — предпросмотр: обновятся **20**, без изменений **0**, не заполнено **0**, ошибок **0**; перечислены восемь допустимых пунктов.
- `07_Подтверждение_обновления_20.png` — запрос подтверждения «Обновить пункт сбора у 20 сотрудников? Другие поля карточек и вид графика не изменяются». Диалог содержит заголовок JavaScript/localhost и английские кнопки, как и другие confirm.
- `08_Список_с_назначенными_пунктами_2_6.png` — после подтверждения в списке отображаются пункты №2 Сургут, №3 Уфа, №4 Саратов, №5 Ленск, №6 Иркутск; ФИО/должности/подразделения и вид графика у видимых сотрудников сохранены. №1 по-прежнему имеет Тюмень.
- `09_Повторная_проверка_20_без_изменений_незаполненных_0.png` — после записи: «Без пункта сбора: 0», повторно выбран тот же XLSX и прочитаны 20 строк. Показатели: **обновятся 0, без изменений 20, не заполнено 0, ошибок 0**; в таблице у показанных сотрудников статус «Без изменений».

## Статус проверки

- **PASS_ALT_SCREENSHOTS — основной сценарий завершён:** XLSX импортируется; все 20 пунктов были предложены к обновлению без ошибок; у видимых сотрудников пункты реально появились; после импорта программа показывает «Без пункта сбора: 0»; повторная проверка тех же 20 записей показывает **«Без изменений: 20» и «Обновятся: 0»**. Это подтверждает идемпотентность на уровне предпросмотра и соответствие сохранённого состояния источнику для 20 строк.
- **Не проверяли:** отклонение неизвестного города, повтора табельного, отсутствующего сотрудника, отмену после предпросмотра, сохранность пунктов после перезапуска, а также прямую проверку всех остальных полей каждой из 20 карточек. Полная устойчивость к прерванной массовой записи не подтверждена.
- **Отложенная неисправность:** нативный GTK/WebKit не скачивает blob CSV, браузер Chromium GOST скачивает, желателен настоящий XLSX (issue #11).
- **UI замечание:** системное диалоговое окно JavaScript/localhost с английскими Cancel/OK для подтверждения импорта пункта сбора, как и в ранее замеченных диалогах; надо русифицировать позже.

Исходные XLSB АвтоГрафа, СЗ РВД, разукрашку и рабочую Windows-базу в ходе проверки не меняли.
