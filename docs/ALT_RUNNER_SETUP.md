# Тестирование LaborControl на ALT Linux через self-hosted runner

## Цель

GitHub будет запускать разрешённые проверки **в виртуальной машине пользователя**, если runner зарегистрирован и работает. Это не предоставляет ChatGPT прямого управления рабочим столом VirtualBox: ChatGPT меняет код и workflows через GitHub, результаты читает из GitHub. Ручные GUI-проверки останутся.

## Текущий этап

- Подготовлена полная матрица: `docs/TEST_MATRIX_R11.md`.
- Добавлена ручная и безопасная задача `.github/workflows/alt-linux-runner-smoke.yml`, без checkout, без установки пакетов, без обращения к рабочим данным.
- Задача запускается **только вручную** через Actions → ALT Linux runner — безопасная проверка → Run workflow, и только на агенте с метками `self-hosted`, `linux`, `x64`, `alt-laborcontrol`.
- Сначала зарегистрировать Runner, убедиться в его работоспособности, убедиться, что он работает от отдельного непривилегированного пользователя, и только потом запускать smoke test.
- Не включать автоматическое выполнение произвольных pull request workflows на self-hosted runner до оценки безопасности и доверия к исходникам. Рекомендуется изолированная VM, которую можно восстановить из снапшота.

## Добавление Runner в GitHub

1. Открыть Settings → Actions → Runners → New self-hosted runner → Linux / x64 в закрытом репозитории.
2. Следовать командам, которые показывает GitHub: ссылка на актуальную версию runner и **временный** регистрационный токен. Токен не присылать в чат и не загружать в репозиторий.
3. Создать отдельного пользователя без `sudo` для runner. Не давать ему доступ к рабочей базе, домашним директориям с SSH-ключами или секретами.
4. При `config.sh` назначить дополнительную метку `alt-laborcontrol` и понятное имя `ALT-VM-LaborControl`, чтобы workflow не был случайно запущен на иной машине.
5. После установки и запуска `run.sh` проверить статус Online в GitHub.
6. Запустить только безопасный smoke workflow, проверить результат.

## Ограничения

- Ветка p11, ALT Workstation K 11.4 (Nemorosa), Git 2.50.1, Go 1.27.4 подтверждены скриншотами.
- Один SSH-ключ deploy keys с правами только на чтение уже настроен. Он **не заменяет** регистрационный токен runner.
- Полноценный функционал R11 ещё не перенесён; такой runner пока сможет проверить среду и ранние компоненты, но не «всю R11».
