# Единая инструкция LaborControl R11: главы, поиск и изображения

**Статус:** отредактировано 22.11.2026; текстовая навигация реализована в PR #15; перенос полноразмерных скриншотов внутрь программного окна — отдельный последующий этап.

## Принцип

Инструкция — **одна система знаний**, а не несвязанные документы. Для неё предусмотрены:
- единое оглавление и понятные темы;
- отдельные главы, которые можно открыть напрямую;
- поиск по названию, содержимому шагов, ключевым словам и синонимам; поиск без учёта регистра и ё/е;
- соответствующий справочный раздел по кнопке прямо на экране сотрудников, импорта, шаблона пунктов сбора;
- локальная работа без интернета; содержание не должно зависеть от веб-сервиса;
- Word-файл как **печатная/внешняя версия** того же материала.

## Структура

| Раздел | Встроенные главы |
|---|---|
| Начало работы | Как пользоваться инструкцией |
| Сотрудники | Добавление из Excel; повторная загрузка и изменения |
| Пункты сбора | Скачать и заполнить шаблон; проверить и внести; ошибки шаблона |
| Карточка сотрудника | Создать вручную; изменить; ошибки сохранения; испытательный срок |
| АвтоГраф | Примечание сотрудника на странице графика |
| Общие действия | Резервные копии и безопасное обновление |
| Краткие сведения | Существующие 17 справок по основным функциям |

Встроенные идентификаторы постоянны: `start`, `employees-import`, `employees-import-recheck`, `points-download`, `points-import`, `points-errors`, `card-create`, `card-edit`, `card-errors`, `card-probation`, `autograf-notes`, `safety-backup`, `quick-0..16`.

**Использование:** открыть в навигации `? Инструкция`; выбрать нужный раздел, затем главу. Для поиска ввести часть текста («табельный номер», «пункт сбора», «испытательный срок»). Результаты фильтруются, первая подходящая глава открывается автоматически. В карточке сотрудника, импорте и шаблоне пунктов сбора есть прямые кнопки на нужную главу.

## Дальнейший этап: снимки экрана внутри приложения

По-прежнему нужно внедрить **локальные изображения** в саму встроенную справку (в PR #15 пока текстовые главы, без изображений). Рекомендуемый формат: версия страницы + WebP/PNG из фактического ALT Linux интерфейса, хранение в ресурсах программы, лёгкие увеличиваемые фрагменты с текстовыми подписями; никакой зависимости от интернета. У картинки не должно быть крупных цифр поверх управляющих элементов.

Контроль:
1. Открыть страницу инструкции на GTK/WebKit.
2. Проверить оглавление, поиск по «табельный номер», «пункт сбора», «испытательный срок», переходы из карточки.
3. Проверить, что по крайней мере один скриншот читается во встроенном окне на стандартном масштабе, а фрагмент можно увеличить.
4. После изменения интерфейса сверить все скриншоты; не переносить устаревшие.
5. Сопоставлять инструкции с актуальной установленной сборкой, не с оригинальными окнами Windows.

## Влияние на данные

Изменения справки — только интерфейс: без новых полей базы и без записи к сотрудникам. Нельзя касаться кадровых данных, расчётов и календаря ради оформления инструкции.
