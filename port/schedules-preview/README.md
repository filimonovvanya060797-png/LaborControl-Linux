# Первый экран графиков LaborControl на ALT Linux

**Статус:** минимальный рабочий прототип **экрана графиков**, а не готовая LaborControl R11. Реальные графики, АвтоГраф, циклы полётов, справочники, проверка табеля и «Разукрашка» не реализованы здесь.

Этот модуль нужен, чтобы начать проверять интерфейс на реальном ALT Linux без отсутствующего исходного Core R11, не трогая рабочую базу.

## Уже можно проверить

- Открытие месячной таблицы графиков в браузере ALT Linux;
- обе колонны (225 + 225 **вымышленных** водителей);
- фильтр колонны и поиск;
- 25 записей на странице, переход между страницами;
- нажатие на день, ручная правка условного плана и сохранение изменений после перезапуска.

**Не является реальным графиком смен:** условные значения только у первых десяти вымышленных водителей (8 в будни, В в выходные), остальные дни пустые. Никаких расчётов АвтоГрафа и бизнес-правил R11 этот прототип не подменяет.

## Запуск

Войти в графический рабочий стол ALT Linux под обычной учётной записью (не `root` и не системным `lc-runner`). Открыть терминал в папке `port/schedules-preview` этой ветки и выполнить:

```bash
CGO_ENABLED=0 go test ./...
CGO_ENABLED=0 go run .
```

Открыть браузер по адресу **http://127.0.0.1:8788**. Для завершения в терминале нажать Ctrl+C.

Для отдельного исполняемого файла:

```bash
CGO_ENABLED=0 go build -o laborcontrol-schedules-preview .
./laborcontrol-schedules-preview
```

Go 1.23 или новее. Сторонние зависимости не требуются.

## Изоляция данных

Прототип никогда не читает `labor_control.json` или `labor_control_tab2.json`. Изменения сохраняются отдельно по адресу `$XDG_DATA_HOME/LaborControl/demo-schedule-overrides.json` или `~/.local/share/LaborControl/demo-schedule-overrides.json`.

**Следующий этап:** на основании архивного Windows-интерфейса и наблюдаемого поведения R11 подключить настоящие модели сотрудников и графиков на **копиях** данных, затем постепенно восстанавливать расчёты и циклы. Нельзя считать прототип функциональным аналогом AutoGraph или закрытия табеля.
