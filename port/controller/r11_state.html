LaborControl · Linux · R11

Локальный модуль хранения и редактирования плановых дней

Загрузка состояния…
Это первый локальный модуль совместимого состояния R11, а не полный Core R11. АвтоГраф, расчёт циклов полётов и проверки пока не перенесены. Импортируйте файл состояния Windows R11, если хотите работать с реальными данными. Файл передаётся только локальному серверу на этом компьютере — не отправляйте его в GitHub или чат.
Изменения сначала накапливаются в таблице. Сохранение выполняется одним пакетом с резервной копией.
Загрузка…

Редактируется только план и плановые часы. Факт, смена, комментарии и неизвестные поля существующих записей сохраняются без изменений.
